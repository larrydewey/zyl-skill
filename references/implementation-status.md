# Specification vs Implementation

The spec (`zyl_specification.txt` v5.0) is normative for the language; the source code is authoritative for what a program does today. Write code against the right-hand column.

| Area | Spec | Today |
|---|---|---|
| Type checking | HM with capability/trait constraints, errors rejected | **sound and enforced** (2026-09-25, `type_annotate.zyl`, spec §4.8–§4.10, `docs/sound-types-design.md`): every type error is reported (`E_TYPE_MISMATCH`, `E_INFINITE_TYPE`, `E_CANNOT_INFER`, `E_UNBOUND_VARIABLE`), then the compile fails. `Unit` is a type (value `unit`), conditions are `Bool`, arithmetic is `Int` or `Float` with no mixing or conversion, statement forms are `Unit`, `main` is `() -> Int`; generalization at top-level SCCs, local `let` monomorphic; no cast form. Runtime entries typed by `compiler/ffi_sigs.zyl`, foreign functions by `(extern ...)`. No known hole (`receive` went with the mailboxes; channels are typed). `ZYL_STRICT_TYPES=report` only counts |
| Generic functions | `((T : Bound) x)` groups, monomorphized | no type-parameter syntax (`((T : Ord) x)` and `(a : Int)` are `E_MALFORMED_PARAMETER`); unannotated params, and any unknown uppercase name in an annotation, are type parameters; a function is specialized per type (`f~T`) where its body depends on the type, and a trait-generic one at every call and every use as a value; more than 256 instances is `E_CANNOT_INFER` |
| Generic ADTs | yes | yes; untyped struct fields are implicit type parameters of the struct |
| Traits | static resolution, bounds, coherence | static resolution only (no run-time dispatch); `trait` signatures type calls, with `Self`; a known receiver with no impl is `E_TRAIT_NOT_FOUND`, an unresolved one `E_CANNOT_INFER`; a trait in type position is `E_MALFORMED_PARAMETER`; prelude `Show Debug Eq Ord Hash Clone Secret`; `impl-not` (`E_IMPL_FORBIDDEN`, with flow rule, both located); orphan rule enforced; duplicates are `E_DUPLICATE_IMPL`; no bounds, defaults, dyn, assoc types |
| derive / alias | generate impls / transparent alias | `derive` generates Show, Debug, Eq, Ord, Hash, Clone impls with field checks (`E_TRAIT_NOT_DERIVABLE`); prelude impls for primitives, List/Option/Result (Vec/Map only Show); `defstruct+ (:derive ...)` rewritten into a `derive`; `alias` is transparent: the name is its target type in every annotation (unknown target or self-reference `E_UNKNOWN_TYPE`) |
| Collections | `Vec<T>`, `Map<K,V>` | `(Vec T)` generic over a typed runtime array (`collections/vec`), `Slice` views on it (`collections/slice`); `(Map String V)` (`core/map`, str-eq keys); `collections/map`/`set` Int-only |
| Views | — | zero-copy `StrView` and `Cursor` (`text/view`), `Slice` (`collections/slice`): ordinary values holding their base, so region inference keeps the base alive; no lifetime parameters |
| Quoted data, list literals | quote, lists | `(list ...)`, `[...]`, `'(...)` (constant data; a name inside is `E_MALFORMED_FORM`, no symbol type), quasiquote `` ` `` with `,` and `,@`; all build typed `Cons` chains left to right |
| Tuples, `defun`, named let, `let*` | yes | no |
| Top-level `def` / Global region | constants | immutable globals, initialized once in source order before `main` |
| Regions | Stack/Heap/Global/Circular/Pin, R1–R8 | real per-call regions (2026-09-24): whole-program escape analysis puts each allocation in the frame region (freed on return/tail jump/unwind), the caller's result region, or the heap (never freed before exit); plus the `IStackVariant` rewrite; `with-region` `arena`/`fixed` scopes (the region extension registry); pin arena; Global and Circular are names only; `E_REGION_ESCAPE` raised for Stack bytebufs and `with-region` values; the type checker does not distinguish byte-buffer regions; `ZYL_REGIONS=0` turns it off |
| Capabilities | TCap/TMut/TAtomic/TBox/TPin inferred | TCap/TMut by name (`let`/`let-mut`); `(Pin a)` from `ffi-pin`; no TAtomic/TBox constructs |
| Closures | capture inference, region-assigned | capture by value, captures keep their types; set! of captures rejected; recursive lambdas unsupported; spawn captures of immutable values work (`let-mut` captures `E_CAPABILITY_LEAK`) |
| Match | exhaustive constructor patterns | exhaustive (constructor-name based); literal/OR/range/guard extension (guards only on literal arms: a guard on a range or `_` arm is `E_ARITY_MISMATCH`, on a constructor arm `E_NESTED_PATTERN`); nested patterns `E_NESTED_PATTERN`; repeated arms `E_UNREACHABLE_MATCH_ARM`; mixed literal and constructor arms undiagnosed |
| Numerics | checked overflow, `E_DIVISION_BY_ZERO` | wrapping; SIGFPE (interpreter reports it); oversized literals → 0 |
| Errors | `error` returns `(Err msg)`; `assert`, `unwrap` | `error` panics/unwinds to `try`; `assert` shows a string-literal message, else `assert failed`; `unwrap` takes an `Option` only, `None` panics `unwrap on None`; no `E_ASSERT_FAIL` |
| Contracts | profiles, injection phase 10 | `requires`/`ensures` (`result` bound)/`invariant` enforced, `E_CONTRACT_VIOLATION`, lowered in `expr_inner.zyl`; profiles strict/debug/warn/off/production via `--contracts=P` or `(contracts P [FORM])`; `recover` arms by error code, in order; `checkpoint` rolls back `let-mut` state (not byte buffers) and re-raises |
| Actors | Kahn channels, deterministic, Send checks | implemented (2026-09-28): `spawn` of a zero-parameter entry returns an `Actor`; typed single-writer single-reader channels (`chan`, `chan-tx`, `chan-rx`, `chan-send`, `chan-recv`), blocking, no select; ends move at spawn (direct captures only) or over a channel (`E_CHANNEL_NOT_OWNER`); closing (`E_CHANNEL_CLOSED`), deadlock detection (`E_DEADLOCK`), per-actor output buffers, panic isolation (`actor-wait` re-raises), at most 1024 actors; `ZYL_SCHED=deterministic` / `ZYL_SCHED_CHAOS=<seed>`; runs in the interpreter too; Send-capability is the syntactic `let-mut`/Secret rule; no shared regions |
| FFI | Pin + pinnable + enforced timeout | foreign symbols need `(extern "sym" (T...) R)` with concrete word-sized types (`Float` rejected); SysV call, ints/pointers only; timeout must be a positive literal (`E_FFI_TIMEOUT_REQUIRED`) and is enforced: foreign symbols run on a worker thread via `zyl_ffi_timed`, `E_FFI_TIMEOUT` on overrun, the C call abandoned; `zyl_*` symbols called directly, typed by `ffi_sigs.zyl`; raw runtime entries restricted to the stdlib (`E_FFI_RESTRICTED`); up to 16 args; pin needed only for Secret; callbacks via a top-level function name, typed `(Fn (A...) R)` (run on the worker thread) |
| Bytes | 8/16/32/64-bit, region rules | 8/16/32/64-bit, le/be; `ByteBuf`/`ByteSlice` types, `Int` offsets/values, each handle the kind its operation accepts; a Stack buffer lives in the frame region and may not escape (`E_REGION_ESCAPE`); other bytebuf region rules unenforced |
| Secrets | (implementation-defined) | syntactic taint checker (impl bodies included); `Secret` fields and `Secret`-trait types, redacted as `<secret>` by `Show`; frames holding secrets zeroed on return (no tail calls); heap erasure manual (`zeroize`/`wipe`); annotations stop at `math/secret/secret`; a `let-mut` ever `set!` to a secret is secret for its scope; diagnostics located |
| Macros | hygienic, innermost-first, terminating | all implemented; identifier params plus a final `&rest name`, spliced with `,@name`; a template is one form; quasiquote exists as a list-building expression (templates themselves are substituted, not quasiquoted: `,x` in a template is `x`) |
| Testing | suites, fixtures, properties, compile tests | implemented (2026-09-28): `test`, `run-tests` (`(:filter "s")` selects by name substring, `(:parallel Bool)` accepted but sequential, other options `E_MALFORMED_FORM`), `assert-equal`/`-true`/`-false`/`-fail`, top-level `test-suite` with `setup`/`teardown`, `test-property` over fixed deterministic samples, compile-time `test-compile`; failing tests print `FAIL: <message>` |
| Evaluation order | strict left to right | strict left to right everywhere (fixed 2026-09-25, `4892ede`: byte offsets vs buffers, a callee value read before its arguments) |
| Stack safety | TCO or heap frames | tail calls are jumps, direct or through a function value, when stack args fit the caller's incoming area (not in `try`/`while` or frame-wiping secret functions); the native backend turns a self tail call into a loop; REPL interpreter TCO except String/Float results; otherwise 64 GiB-reserved stack for `main`; actors 8 MiB |
| ICNF | SSA with region annotations | untyped structured tree, not SSA; region annotations in the `icnf-regions` side table (`node_tables.zyl`), printed as ` @r` by `icnf_print` (so covered by the package-build ICNF hash); `IRegion` for `with-region` |
| Optimization | safe only | ICNF: inlining of small non-recursive functions with Int-kind parameters (`ZYL_INLINE_LIMIT` nodes, default 6; leaf functions calling only the runtime up to 4× that; `ZYL_INLINE=0` off), one-level unrolling of small tree recursion (`ZYL_UNROLL`), early exits at loop call sites, copy propagation, int constant folding, dead-branch elimination; after region inference, in-place reuse of unique dead values (`reuse.zyl`, Perceus-style, owning clones `f~own`; `ZYL_REUSE=0` off; [icnf-reuse-pass](../rules/icnf-reuse-pass.md)). Native backend: immediates, cmp-and-branch, division by a constant as a multiply, frameless leaf functions, loop rotation and aligned loop heads, accumulator tails, proven-range bounds-check removal in guarded loop copies. Nothing reorders side effects |
| Code generation | x86_64 | two backends, one ABI: the native backend (ICNF → MIR in `mir.zyl` + the NATIVE BACKEND section of `codegen.zyl`, linear-scan register allocation over `rsi rdi r8 r9 r10` and callee-saved `rbx r12–r15`, scratch `rax rcx rdx r11`) compiles about 95% of functions; the stack machine takes the rest (`mb-eligible` fails on closures, `try`, `print`, Float arithmetic, `with-region` scopes, more than 6 parameters, frame-wiping secret functions). `ZYL_MIR=0` sends everything to the stack machine ([cg-native-backend-mir](../rules/cg-native-backend-mir.md)) |
| Linking | — | a program with no foreign `ffi-call` and no native objects is assembled (`asm_x86.zyl`) and linked (`elf_link.zyl`) by the compiler into a static executable with no libc, against the cached runtime `rt.zo`; hosted programs link with `cc` + `rt.o` over libc; `ZYL_EXTERNAL_LD=1` uses `cc` always ([cg-self-link](../rules/cg-self-link.md)) |
| Runtime | — | Zyl (`runtime/rt/`, no C), compiled with `--runtime-module`; locked `%` primitives; own allocator, threads (`clone` + futex), `_start`, buffered stdout; try frames pointer-mangled with a per-process guard ([boot-runtime-module](../rules/boot-runtime-module.md)) |
| Intrinsics | §21.13 | `bit-popcount`, `bit-clz`, `bit-ctz`, `bit-bswap`, `bit-rotl`, `bit-rotr`, `mul-hi`, `mul-hi-u`, `crc32c`, `crc32c-u8`, 32-bit forms; `stdlib/simd` lane vectors (portable SWAR); no inline assembly ([bits-intrinsics](../rules/bits-intrinsics.md)) |
| Pipeline | 11 phases | see [pipeline.md](pipeline.md); region inference and reuse run on ICNF after optimization; contracts lowered in the front end (`expr_inner.zyl`), no separate injection phase |
| Language server | — | `zyl-lsp` runs the checks and the type checker and publishes every located error and warning (`dm-type-diagnostics`); hover, completion, go-to-definition, document symbols, semantic tokens, signature help, inlay hints, call hierarchy, balance fix-it code actions; UTF-8 preserved, but positions are byte columns (not UTF-16) |
| Packages (§31) | full | implemented; `ZYL_INDEX` selects an index (git URL or local path), `zyl publish --index DIR` adds to one, but the default hosted index does not exist yet; git deps cloned by revision; content-hash build cache for `zyl build`/`test`; only root native block built; vendor unused; the capability check covers `main` and top-level tests, but not manifest-less files |
| Hash finalization | ICNF hash etc. | package builds only: `.buildinfo` with compiler, graph, native-object and ICNF hashes, the resolved graph, asm hash (informational) and final hash, embedded in the binary as `zyl_build_hash` |
| Determinism | total | holds for FFI-free programs, actors included; assembly and binaries reproducible (register allocation and reuse decisions depend on instruction order only; the Zyl assembler and linker are byte-deterministic) |
| Reserved keywords | `E_RESERVED_KEYWORD` for all | implemented (2026-09-28) for every name a definition form introduces, and `make-S` for a struct `S` in the same file; standard library and runtime exempt |
